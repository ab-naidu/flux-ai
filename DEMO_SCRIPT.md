# 3-minute demo script (Multimodal Frontier)

Use a **clean take**; show **`/ui/`** full screen first, then optionally **Network** tab for `X-Flux-Sponsor-Tools`.

**Theme hook (say this early):** The event is about agents that **see and understand the real world**, not just process text prompts. Flux’s input is **real dock imagery**—invoice plus pallet in one frame.

## 0:00–0:22 — Idea (20%)

> “Most warehouse agents would still be typing what someone *said* was on the truck. We’re doing the opposite: the agent **looks** at **real receiving photos**—invoice and goods together—extracts structured counts, flags variance, and only then talks to inventory APIs under policy. That’s multimodal **vision** on **real operations**, not a text-only copilot.”

## 0:22–1:45 — Live demo: Autonomy + Technical (20% + 20%)

1. Open **`/`** or **`/ui/`** (redirects to demo).
2. Paste **Unkey** client key; upload **one strong image** (invoice + boxes).
3. Click **Run agent**.
4. **If green banner** (“FULL — zero variance → sync”): point at it — *“No extra clicks—the agent closed the loop.”*
5. **If yellow banner** (HITL): read variance table — *“Autonomy pauses for safety.”* Click **Approve & sync** — *“Human-in-the-loop, then Unkey-gated POST.”*

## 1:45–2:35 — Tool use (20%)

> “**Google Gemini** does vision and JSON extraction. **Unkey** validates every mutation. **trace_id** gives us Railtracks-style audit. The API runs in a **Dockerfile** ready for **DigitalOcean**. We have a bundled **UI**; you can also pair **Lovable** and **Assistant UI** for the same API.”

Optional: open **`/api/about`** in another tab — *“Everything we claim is enumerated here for judges.”*

## 2:35–3:00 — Close (Presentation 20%)

> “Public **GitHub**, **Shipables** skill for agent install, and this flow is one vertical slice we’d pilot with a DC or grocery receiving team. Questions?”
